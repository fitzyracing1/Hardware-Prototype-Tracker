# Hardware-Prototype-Tracker

A lightweight setup for tracking hardware prototypes, BOMs and progress with GitHub's own tools. Updates are dictated or typed on a phone as issue comments or through an issue template, and a GitHub Projects board shows the status. The repo contains no code.

| Path | Content |
|---|---|
| `projects/*.md` | one page per project: Tesla Bot Cruiser, Open Source Spaceship, Nanocraft, Organic Spin Processor |
| `.github/ISSUE_TEMPLATE/hardware-progress-update.md` | structured "Hardware Progress Update" issue template |
| `docs/index.html` | site |

## Getting started

1. Open the repo's Issues tab, either on a phone or in a browser.
2. Comment on a project's tracking issue, or open a new issue from the "Hardware Progress Update" template.
3. Add the issues to a GitHub Project (board, table or roadmap view) for the dashboard. The README has the one-time setup steps.

No automation turns comments into structured fields. Updates stay as issue text. The repo has no LICENSE file.
